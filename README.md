# Cyberpunk Custom Launcher & Save Editor

A custom launcher and save editor for Cyberpunk 2077. Deploys REDmod-format
mods, scans installed archives for conflicts, and provides a save editor for
adjusting proficiency levels, Street Cred, and other stats through a
Cyberpunk-styled interface.

See [BUILD.md](BUILD.md) for full build instructions, source file layout,
and architecture notes. See [LICENSES.md](LICENSES.md) for the embedded
font licenses.

## Requirements to run

- Windows
- A copy of Cyberpunk 2077

No other mods or tools required.
